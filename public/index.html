API Reference

Endpoints Directory

Complete reference of available REST endpoints across the Soundtrack & Spotify engines.

v1

Movie Soundtrack Engine

Turso LibSQL
GET /v1/titles/imdb/:imdb_id/music

Lookup Spotify soundtrack playlist by IMDb ID (e.g. tt13070038)

GET /v1/titles/tmdb/:tmdb_id/music

Lookup Spotify soundtrack playlist by numeric TMDB ID (e.g. 993710)

GET /v1/titles/slug/:slug/music

Lookup soundtrack playlist by URL-safe movie slug (e.g. apex-2026)

GET /v1/titles

List all cataloged movie titles with soundtrack association counts

Integration

Client Quickstart

Integrate SoundTrackDB into your frontend or backend application in seconds.

# 1. Resolve movie soundtrack by IMDb ID
curl -s "https://soundtrackdb.cnf1g.com/v1/titles/imdb/tt13070038/music"

# 2. Or search tracks directly from Spotify catalog
curl -s "https://soundtrackdb.cnf1g.com/api/search?q=Faded&type=track&limit=5"
// Fetch movie soundtrack using native fetch
const res = await fetch('https://soundtrackdb.cnf1g.com/v1/titles/imdb/tt13070038/music');
const data = await res.json();

console.log('Title:', data.title.name);
console.log('Spotify Playlist:', data.music[0]?.url);
import requests

# Resolve movie soundtrack by IMDb ID
url = "https://soundtrackdb.cnf1g.com/v1/titles/imdb/tt13070038/music"
response = requests.get(url).json()

if response.get("success"):
    title_name = response["title"]["name"]
    spotify_url = response["music"][0]["url"]
    print(f"{title_name} soundtrack: {spotify_url}")
Architecture

Engine Specifications

Autonomous micro-architecture designed for resilience and zero vendor lock-in.

Ephemeral TOTP Generation

Uses ephemeral token generation synchronized to Spotify's web player infrastructure. Cron rotates tokens every 30 minutes to guarantee high availability without developer keys.

Turso LibSQL Edge Store

Curated movie soundtracks are normalized and persisted in an ultra-low latency distributed SQLite database on Turso, providing instant sub-10ms query responses.

Confidence Scoring Engine

Every soundtrack playlist match includes confidence weights (1.0 = official & verified, 0.8 = community verified) and match categorization (exact ID vs agnostic text search).
